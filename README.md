## 以后如何更新

1. 复制每日模板，保存为 `logs/week-XX/day-XX.md`。
2. 补充当天材料、实际回答、修订、检验结果和下一次复习任务。
3. 将可复用问答加入 `knowledge/`，使用稳定卡片编号。
4. 更新本页进度，并用一次 Git 提交保存当天变化。
5. 每周用新问题检验迁移；计划、用户自述完成、来源可观察表现、正式验收分别记录。

目前仅 Day 01 为实际学习档案，其余天数是后续计划。仓库不会自动抓取未来记录，需在每次学习后更新。
